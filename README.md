# Weather App 🌦️

A weather application built using HTML, CSS, and JavaScript that fetches weather information using a weather API.

## 🌐 Live Demo

[Visit Weather App](https://nikhilsharma28.github.io/weather-App/)

## ✨ Features

- Search weather by city name
- Display temperature and weather conditions
- Show humidity and wind speed
- Display date and time information
- Fetch weather data using an API
- User-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Weather API
- Geocoding API
